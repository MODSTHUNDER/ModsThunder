**ModsThunder** is a modern, fast, and user-friendly mod manager designed to help gamers easily discover, install, and manage mods for their favorite games.

</div>

---

## 🚀 Features

* **One-Click Installation:** Integrate mods directly into your game without dealing with complex file directories.
* **Automatic Updates:** Track new versions for your installed mods and update them with a single click.
* **Profile Management:** Create different mod combinations (presets) and switch between them seamlessly.
* **Dependency Management:** Automatically detects and installs required dependencies and libraries for your mods to work properly.
* **Modern & Fast UI:** A clean, responsive design built with user experience in mind.

---

## 📥 Installation

1. Go to the [Releases](https://github.com/MODSTHUNDER/ModsThunder/releases) page.
2. Download the latest version compatible with your operating system (`.exe`, `.AppImage`, etc.).
3. Run the application and scan for your supported games.
